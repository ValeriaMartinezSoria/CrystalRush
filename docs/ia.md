# Registro del uso de IA

Este proyecto fue construido con asistencia de IA a partir de las especificaciones del examen.

- Se solicitó crear la estructura React + TypeScript, Express + TypeScript, configuración de lint, Playwright, workflows y documentación.
- Se incorporaron ideas de arquitectura: estado en memoria del backend, cuadrícula discreta, API JSON y servidor Express para el frontend compilado.
- Se revisaron manualmente los tipos, las validaciones de movimiento, la regla del Pulso Energético, la generación de posiciones y los mensajes de error.
- Se ejecutaron compilación y lint de frontend y backend, además de solicitudes HTTP locales para GET, reinicio y movimiento fuera del tablero.
- Las pruebas E2E se ejecutaron en Chromium headless después de instalar el navegador: las 6 pruebas pasan localmente y contra la aplicación publicada.
- El estudiante debe revisar y explicar el código, ajustar estilos y ejecutar las pruebas antes de entregar.
